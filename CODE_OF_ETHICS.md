# Code of Ethics

This tool, **hx-password-security-engine**, is designed strictly for **educational and
defensive purposes**.

## Guiding Principles

1.  **Do No Harm**: This tool must never be used to target, attack, or compromise
    systems that you do not own or have explicit permission to test.
2.  **Privacy First**: The password analysis logic runs entirely locally. No passwords
    or data are ever transmitted to any external server.
3.  **Education Over Exploitation**: The features provided (entropy calculation, crack
    time estimation) are intended to demonstrate the mathematical concepts behind
    password security, not to facilitate cracking.
4.  **No Brute Force**: This tool does not contain, supporting, or encourage brute-force
    attacks. It is an analytical engine, not an offensive weapon.

## Usage Agreement

By using this software, you agree to:

- Use it only for lawful purposes.
- Respect the privacy and security of others.
- Not use the probabilistic data to harass or intimidate.

Failure to adhere to this code of ethics violates the license and intended use of this
software.
