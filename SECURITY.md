# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please prioritize responsible disclosure.

1.  **Do NOT** open a public GitHub issue.
2.  Report the issue directly to the maintainers.
3.  Include a proof of concept (PoC) if possible, without exposing any sensitive real-world data.

We are committed to addressing valid security concerns promptly.

## Safe Harbor

We support safe harbor for security researchers. If you are conducting security research on this open-source tool:

- You will not be prosecuted or threatened with legal action by us.
- We will work with you to understand and resolve the issue.

Please note that this safe harbor applies only to this specific codebase and not to any third-party systems or the infrastructure of users utilizing this tool.
